# Smoke-чеклист бренда — Desktop

## Назначение

Быстрая проверка того, что бренд доступен и его ключевые пользовательские сценарии работают после релиза, конфигурационных изменений или перед полным регрессионным прогоном.

Проверки выполняются без реального пополнения, вывода средств и ставки. Если такие операции входят в область релиза, используйте только согласованное тестовое окружение и тестовые средства.

- Быстрый release gate: выполнить все применимые `P0` (ориентир — 20–30 минут).
- Расширенный smoke: выполнить `P0` и `P1` (ориентир — 45–75 минут).

## Карточка прогона

| Поле                            | Значение                                        |
| ------------------------------- | ----------------------------------------------- |
| Бренд / URL                     |                                                 |
| Окружение / версия / commit     |                                                 |
| Дата и время, часовой пояс      |                                                 |
| Тестировщик                     |                                                 |
| ОС                              |                                                 |
| Браузер и версия                |                                                 |
| Viewport                        | `1440 × 900` основной; `1366 × 768` контрольный |
| Гео / VPN                       |                                                 |
| Тестовый игрок / валюта         |                                                 |
| Ссылка на автоматический репорт |                                                 |
| Ссылка на баги                  |                                                 |

Пароль, токены, cookie и платежные данные нельзя помещать в публичный репорт или скриншоты.

## Статусы и приоритеты

- `PASS` — ожидаемый результат получен полностью.
- `FAIL` — воспроизводимый дефект продукта.
- `BLOCKED` — проверка невозможна из-за WAF, окружения, данных или внешнего сервиса.
- `N/A` — функция отсутствует у бренда по требованиям; требуется комментарий.
- `NOT RUN` — проверка еще не выполнялась.
- `P0` — критический release gate: отказ означает `NO-GO`.
- `P1` — важная smoke-проверка: отказ требует оценки владельца продукта перед релизом.

Нельзя заменять `FAIL` статусом `N/A` или `BLOCKED`. Причина каждого `BLOCKED` и `N/A` должна быть указана в комментарии.

## Предусловия

- [ ] URL, окружение, разрешенное гео и ожидаемая конфигурация бренда подтверждены.
- [ ] Cloudflare/WAF допускает тестовый браузер; нет бесконечного challenge-loop.
- [ ] Подготовлены новый и существующий тестовые игроки, если регистрация доступна.
- [ ] Для платежных проверок задана валюта и доступен игрок с подходящим статусом.
- [ ] Отключены расширения браузера, способные менять страницу; DevTools доступны.
- [ ] Первый проход начинается в чистом контексте, авторизованные проверки — в отдельной сессии.
- [ ] Известны допустимые ограничения провайдеров, гео и KYC.

## Критерии завершения

- `GO`: все `P0` имеют `PASS`; для `P1 FAIL/BLOCKED` есть заведенные баги и принятое владельцем продукта решение.
- `NO-GO`: любой `P0 FAIL`; невозможны загрузка, регистрация/вход, каталог/игра, Sports/betslip или открытие платежного сценария.
- Прогон нельзя считать завершенным, пока `NOT RUN` остается у применимых `P0`.

## Автоматизированная базовая проверка

Замените `<brand>` на slug бренда:

```bash
node scripts/qa-brand-run.js --brand=<brand> --mode=desktop --profile=core
```

Автоматический прогон дополняет чеклист, но не заменяет ручную визуальную и продуктовую проверку.
