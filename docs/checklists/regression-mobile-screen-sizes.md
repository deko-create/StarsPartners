# Регрессионный чек-лист Mobile — популярные разрешения экранов

## Назначение и выбор разрешений

Чек-лист дополняет [полный mobile-регресс](./regression-mobile.md) и проверяет responsive-поведение брендов на трёх наиболее распространённых мобильных CSS-разрешениях.

Обязательная матрица выбрана по мировой статистике StatCounter за октябрь 2026 года:

| Профиль | CSS viewport |   Доля | Класс устройства                        | Основной риск                                      |
| ------- | ------------ | -----: | --------------------------------------- | -------------------------------------------------- |
| `M414`  | `414 × 896`  | 12,67% | Крупный телефон / iPhone Plus-Max класс | Растянутые блоки, пустоты, неверная ширина модалов |
| `M360`  | `360 × 800`  |  8,57% | Компактный Android                      | Переполнение, обрезанный текст, недоступные CTA    |
| `M384`  | `384 × 832`  |  7,24% | Средний Android                         | Ошибки промежуточного breakpoint                   |

Источник: [StatCounter Mobile Screen Resolution Stats Worldwide](https://gs.statcounter.com/screen-resolution-market-share/mobile/worldwide), октябрь 2026.

Дополнительный рекомендуемый профиль: `390 × 844` — распространённый iPhone viewport и следующая позиция мировой статистики. Он не заменяет три обязательных профиля.

## Настройки выполнения

- Ориентация по умолчанию: portrait.
- Browser zoom: `100%`.
- Touch и `isMobile`: включены.
- Meta viewport применяется без искусственного desktop scaling.
- DPR и физическое разрешение устройства фиксируются отдельно: проверка проводится по CSS viewport.
- Основной браузер Android-профилей: Chrome Mobile.
- Для release-кандидата повторить P0 на реальном iPhone/Safari или WebKit-профиле.
- Guest и authorized проверки выполнять в отдельных чистых контекстах.
- Для каждого профиля выполнить минимум один cold load и один reload.
- Проверить portrait полностью; landscape — минимум P0-навигацию, модалы, Casino game и Sports betslip.
- `P0 FAIL` хотя бы на одном обязательном профиле означает `NO-GO` для mobile.

Для каждого профиля сохранить минимум:

1. Главная — верх страницы и footer.
2. Открытый sidebar.
3. Sign Up или Log In с открытой клавиатурой.
4. Casino default и Search/Filter.
5. Запущенная игра portrait и landscape.
6. Sports с открытым betslip.
7. Profile.
8. Deposit/Withdraw без подтверждения транзакции.
9. Live Chat или Smartico.
10. Каждый дефект до и после взаимодействия.

Формат имени: `<brand>-<profile>-<route>-<state>.png`, например `casho-M360-sports-betslip.png`.

## Критерии завершения

- `GO`: все применимые P0 прошли на M360, M384 и M414; P1-дефекты заведены и оценены.
- `NO-GO`: любой P0 недоступен хотя бы на одном обязательном профиле; присутствует horizontal overflow, перекрытие navigation, недостижимый Close/submit или сломанный touch-flow.
- `PARTIAL`: один профиль, orientation или обязательный раздел не проверен; такой результат не считается полным mobile-регрессом.
